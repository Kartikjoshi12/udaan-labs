# Udaan Labs — Retro Desktop

Experimental portfolio as a **retro desktop metaphor** with **neo-brutalist** and **editorial** styling.

## Look & feel

- Desktop icons + draggable/resizable windows + taskbar
- Neo-brutal thick borders + hard offset shadows
- [Pixelarticons](https://pixelarticons.com/free/) (MIT) for UI icons
- [Kenney Pixel UI Pack](https://kenney.nl/assets) (CC0) for panel textures
- Project photos in `public/projects/`
- Mobile = pocket OS home screen + fullscreen apps

## Credits

- Icons: [pixelarticons](https://pixelarticons.com) by Gerrit Halfmann (MIT)
- UI panels: [Kenney.nl](https://kenney.nl) Pixel UI Pack (CC0)

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) · hard refresh `Ctrl+Shift+R`.

## Content

Edit copy in `src/lib/site.ts`.

## Wallpapers

Paste images into:

```
public/wallpapers/
```

Name them `1.png`, `2.jpg`, `wallpaper.png`, etc.  
Refresh the site — desktop picks one automatically.  
See `public/wallpapers/README.md`.
